WebAssembly · no plugin · no install

C apps that run in your browser

RayClay is a C framework for building complete apps for desktop, mobile, and the web. Every demo below is the same C source that compiles to a native desktop window, rebuilt for the web with one command: no web port, no second UI. What you are about to click is not a video or a screenshot. It is the app. 

/* the whole program */
#include "rayclay.h"
int main(void) { return rcRunApp(NULL); }

$ cmake --preset web        # -> a page you can host anywhere

Start here : the two-line program

ex00

Hello, RayClay

The two lines above, running. A window, a font, a render loop, with no assets on disk and nothing to configure.

The flagships : real multi-file apps, not snippets

ex20

System monitor

This device's real readings over a Grafana dashboard of three simulated servers: stat panels, gauges, time series with legend tables, a process table and a Services tab. On the desktop its titlebar carries the real window controls; here the browser tab is the chrome.

 ex21

Photo library

An Apple Photos-style library whose pictures are generated at runtime: albums, a density switch that really regroups, a viewer with basic edits, and a film played by the browser's own video element with captions on the playhead.

 ex22

Notes

A Bear-style notes app: live Markdown, wiki links, tags and search, and a reading mode with a table of contents that follows the scroll.

 ex23

Trading terminal

A TradingView-style terminal: a candlestick chart drawn from primitives with a crosshair and a live price line, a watchlist, an order book and an order ticket over a simulated market.

 ex24

Messenger

A consumer messenger: chats, reactions, simulated people who answer, and an optional live room over a WebSocket: run serve.py and connect.

ex21-ex24 with ex29 are the project's benchmark suite as well as its showcase: the same source that ships is the source we measure. Nothing here is written twice.

Full apps, continued : one job each, done properly

ex25

A kanban board, in C++

A Trello-style board from a C++20 translation unit, with real drag and drop and an optional REST sync: run serve.py and connect. The file a C++ developer copies.

 ex26

Data explorer

12,000 orders behind a query bar, facets and a trend you brush to filter. The table drops columns and says so instead of scrolling sideways.

 ex27

Issue inbox

GitHub Issues over 100,000 issues. Type in the filter and the whole list re-selects; scroll it and only a screenful of rows is declared, because the window sets the cost of drawing, not the dataset.

 ex28

IDE

A VS Code-style editor for C, Markdown, JSON and SVG, with a live SVG preview, drawing art three ways: by path with rcSvg, from a handle you loaded, and compiled in from a generated header.

 ex29

Pulse Dash

A rhythm platformer whose titlebar plays the course's waveform: an app framework running a game that ticks at 60 Hz.

Forty years of interface, one API : the same widgets, five eras

ex01

1980s: 1-bit desktop

A 1984 Macintosh desktop: the Calculator desk accessory, a Finder window, menus that work, and not a color in sight.

 ex02

1990s: silver bevels

The Windows 95 desktop: Display Properties in full 3D-bevel regalia, a taskbar with a Start button and a clock, and Apply that really repaints the wallpaper.

 ex03

2000s: gloss and gel

An iTunes-era media player: brushed metal, gel buttons, an LCD, and a striped song table.

 ex04

2010s: flat and material

A Material tasks app: a card on a gray page, a floating action button, and a snackbar with UNDO.

 ex05

2020s: the dark dashboard

A modern SaaS console: soft shadows, rounded surfaces, and a muted dark palette.

Five decades of visual language, drawn by one API and one renderer. The period chrome is deliberate art, not a platform theme; RayClay ships no OS look-alike.

Components and tools : copy one into your app

ex06

Widget gallery

Every RayClay widget, browsed like Storybook, plus live re-tintable icons: an icon's color is just an argument you pass each frame.

 ex11

Live inspector

RayClay watching itself, laid out like browser DevTools: live fps and frame-time tracks, a console that follows its own tail, fed by RayClay's own diagnostics.

 ex12

Sign-in

The sign-in page every account-based app opens on, as one call to copy: Google, email, a password reset and a one-time code. On macOS and iOS, Apple joins Google.

 ex14

File selector

An open panel to copy, over the page's own stored files: places, a sortable table, search and a preview.

 ex15

File browser

A Finder-shaped browser over a sample drive: icon, list and column views, Quick Look and rename, with the browser's file picker and drops.

Resize the window; the layout reflows, because it is a real layout engine, not a scaled bitmap.
