# The media profile's upstream decoders (vendored; two carry RayClay patches)

RayClay's media profile is one static archive, `librayclay_mediaprofile.a`, built by the profile's own
`CMakeLists.txt` (beside these files) from the upstream files here and RayClay's own bridges. A program links it
beside the header; one that opens no media file and loads no image links none of it (each bridge's table is reached
only through the address the public macro passes from the caller's translation unit). Every file here is upstream's,
byte for byte, but `dr_flac.h` and `stb_vorbis.c`, which carry the fixes `RAYCLAY-PATCHES.txt` lists
(each marked "RayClay patch N" at its site); that file also says how RayClay builds them otherwise unedited. libvpx's
generated configuration and RayClay's renames of its names are the other exceptions (below).

- **Download URLs, commits and per-file pins:** `PINS` (TOML). dr_mp3, dr_flac and stb_vorbis are each one file at a
  pinned commit; libwebp is the 87 files of the signed release tarball
  https://storage.googleapis.com/downloads.webmproject.org/releases/webp/libwebp-1.6.0.tar.gz (sha256
  `e4ab7009bf0629fd11982d4c2aa83964cf244cffba7347ecd39019a9e38c4564`, signed by the WebP release signing key
  `6B0E 6B70 976D E303 EDF2  F601 F9C3 D6BD B823 2B5D`) that upstream's own build compiles into libwebpdecoder and
  libwebpdemux, less the MIPS sources, at their upstream paths under `libwebp/`.
- **libvpx** is the 177 files of tag `v1.17.0` (commit `6df3ec34557879fff673706f4a1d9fbd0f3a6f0e`) that its
  decoder-only build compiles and reaches, at their upstream paths under `libvpx/`, with the six headers upstream's
  `configure` generated for a portable C build (threads on, frames up to 8192 a side; the options are in `PINS`),
  so nothing is configured or assembled here. RayClay's `rc_mp_vpx_names.h`, beside the bridge, renames every
  libvpx global into `rci_media_vpx_lib_`, so a program's own libvpx never meets the profile's.
- **nestegg** is its demuxer and header at a pinned commit, under `nestegg/`; **libopus** is the 116 sources and
  headers of Xiph's release tarball https://downloads.xiph.org/releases/opus/opus-1.6.1.tar.gz (sha256
  `6ffcb593207be92584df15b32466ed64bbec99109f007c82205f0194572411a1`, as Xiph's `SHA256SUMS.txt` lists it) that its
  multistream decoder links, floating point, under `opus/`, with its COPYING, AUTHORS and LICENSE_PLEASE_READ.txt.
- **Apple hosts link none of libwebp:** ImageIO decodes WebP there, inside RayClay's library.
- **Checkable here:** `shasum -a 256 -c` holds every file to the list below, which matches each file's `sha256` in
  PINS (PINS also records its `size`); PINS lists every file under `libwebp/`, `libvpx/`, `nestegg/` and `opus/`, and
  both anchors name the profile's TAG.
